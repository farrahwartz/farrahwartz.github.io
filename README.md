# Farrah Wahida Artz — Workshop Portfolio

Live site: https://farrahwartz.github.io/

A one-page collaboration profile featuring facilitated workshops, selected art-learning programmes, workshop galleries and Malaysian television features.

## Included

- Floral watercolour, cursive lettering and acrylic pour workshop offerings.
- Documented sessions at BookXcess LaLaport, with IIUM Arts Club, and the 2023 Ramadhan Charity Watercolour Workshop.
- Buletin Utama TV3 and Buletin 9 features supplied by Farrah.
- Business email and Instagram contact links.
- Responsive HTML/CSS with local images and no build process.

## Update the site

1. Open this repository on GitHub.
2. Edit `index.html` using the pencil icon.
3. Commit the change; GitHub Pages will republish the site.
4. Upload new photos into `assets/` and reference them as `assets/filename.jpg` in the HTML.

Historical prices in archived event posters are not current rates. Confirm a current rate card before publishing specific prices.
