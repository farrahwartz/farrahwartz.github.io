# Farrah Wahida Artz — Workshop Portfolio

Live site: https://farrahwartz.github.io/

A one-page collaboration profile for workshop venues, private groups and organisations.

## Content status

The following items need Farrah's verified details before the site is shared with collaborators:

- Business email, WhatsApp number and Instagram URL in `index.html`.
- A real teaching or floral artwork photo at `assets/hero.jpg`.
- Verified workshop history and media features.
- Confirmed pricing, inclusions and terms.

No experience figures, media features, testimonials or rates have been invented.

## Update the site

1. Open this repository on GitHub.
2. Open `index.html`, select the pencil icon, and edit the clearly marked sections.
3. Select **Commit changes**. GitHub Pages will publish the update, usually within a few minutes.
4. To add a photo, upload a JPG named `hero.jpg` into the `assets` folder. Keep the optimised image below roughly 500 KB for faster mobile loading.

The site is plain HTML/CSS/JavaScript and does not require a build command or external dependencies.
